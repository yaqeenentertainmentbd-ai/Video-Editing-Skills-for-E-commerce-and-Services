## 1. Key finding: how captions are really made

Captions are **not** made in Premiere/After Effects/CapCut. They are HTML + GSAP compositions rendered by **HyperFrames** (`npx hyperframes render`), generated by Python builders. Fonts load through `@font-face` from `assets/fonts/`, so **system installation is not needed for HyperFrames renders**. System install matters only for Premiere/AE/Resolve/CapCut/FFmpeg and for the Python measuring tool (`textfit.py` reads the same files).

Premiere projects (`*.prproj`, 2025-09 to 2026-10) contain no readable caption font. The only decoded text layer (Spiralyze `main.prproj`, "Mister Horse Adjustment") uses `Arial-BoldMT`, 36.7 pt, white: a plugin template, not a caption style.

## 4. Caption styles (details in `Presets/caption_presets.json`)

### 4.1 `SAGE-REEL-916` Sage Reel Caption (main style, 9:16 1080x1920, 30 fps)
Lead line + boxed punch word. Used in reels 01-05 (`reel_build.py`, `reel02..05_build.py`; identical CSS).
- Lead: Poppins/Hind Siliguri 400, 50 px, lh 1.25, #fff, shadow `0 1px 2px rgba(0,0,0,.3)`.
- Punch (the `*emphasis*` words): Poppins/Opekkha 700, 92 px, lh 1.16, #fff, nowrap, on a **#4f8462** box, radius 16, padding `2 28 12`, shadow `0 2px 6px rgba(0,0,0,.16)`.
- Tail (words after punch): 46 px 400. Solo line (no emphasis): 72 px 700.
- Box: left 50, width 980, centred. `bottom` 1010 in "stack" framing (panel in bottom half), 330 in "full" framing. Face sits near (940,420) on the 1920x1080 source.
- Wrap: punch over 16 plain chars is cut after the emphasis end and the rest becomes tail; box wider than 980 prints a warning.
- Case: none (Bangla); English as typed. Letter spacing 0. No stroke. Alignment centre.
- Animation: lead words fade+rise 12 px+blur 4->0, 0.24 s `power3.out`; box `scaleX 0->1` 0.30 s `expo.out`; punch text slides from x -26 0.34 s; multi-word punch rests at 42% opacity then lights up word by word; group out 0.08 s.
- Timing: caption list `(start, end, text, start_of_last_word)` on the source clock; word times are spread by character count between start and last-word start. Each caption holds to 0.04 s before the next, so captions cover ~100% of speech. Captions never cross a cut; after a full/stack reframe they wait 0.35 s.
- Reasoning (from the code comments): never sit on the face; never change zone mid-caption; always something on screen because viewers watch muted.
- Also in this style: hook title (96 px 700, top 1070, green-boxed em, pill 40 px/600) and end pill (40 px/600, top 1700, "ফলো করুন — পুরো ভিডিও চ্যানেলে").
- Use for: Bangla/English explainer reels, tutorials, Claude/AI content.

### 4.2 `SAGE-FILM-169` (16:9 1920x1080, `build.py`)
Same family, scaled by CSS variables: lead 300 (42 px, solo 500/46 px), hero lead 0.44x, hero solo 0.62x, punch default 78 px lh 1.18, box radius 14 padding `2 26 10`, tail 0.5x. Subtitle placement `bottom:86`. Ink variant (#10261a, no shadow) on white paper cards. Pill: Poppins 600 32 px, tracking .02em. Auto-fit by HarfBuzz widths (`textfit.py`): full size, shrink to 0.82x, emphasis run only, then two lines.

### 4.3 `ORANGE-BN-REEL-916` (10-18-26 "AI Edited This")
Three rows: top / big / tail. Colour `#fbf8f3`; accent `#f26419`; gradient highlight `#ffa43a -> #f26419 -> #d9480f`. Container top 1150, height 330. Big variants: black (Montserrat 900, 96 px, -0.035em), bold (700), thin (200, -0.01em), serif (Instrument Serif italic 124 px). Top 46/40 px 400, tail 46/38 px 300. Gradient highlight box radius 10. Effects: `shine`, `bounce`, `ticker`. Per-word timestamps inline (`word@time`). Use for personal-story reels; flips to ink on paper scenes.

### 4.4 Not found / not claimed
Karaoke, outline/stroke captions and cinematic minimal subtitles do not exist in the projects. No stroke is used anywhere (shadows are the only edge treatment). No client-specific caption style is verified. Do not invent them.

## 5. Install & verify (permission required)

Only install with the user's go-ahead. Never run downloaded scripts, never bypass UAC/Gatekeeper.
1. Read `Font_Manifest/font_manifest.json`. Check each file's sha256 (`python Scripts/verify_fonts.py`).
2. Windows per user: `powershell -ExecutionPolicy Bypass -File Scripts\install_fonts.ps1`. macOS/Linux: `bash Scripts/install_fonts.sh`. Details, duplicates, caches, app restarts: `Installation/*.md`.
3. Opekkha: not in the library. Get from FontBD, or from the user's private copy.
4. Missing fonts you may fetch: only from the "verified download pages" in the manifest (Google Fonts/GitHub). Compare family and PostScript name with the manifest.
5. Re-run `verify_fonts.py`. Result on the original PC (2026-10-31): Poppins (8), Montserrat, Abu Sayed, Opekkha installed; **Hind Siliguri and Instrument Serif not installed system-wide**, which is fine for HyperFrames (embedded) but not for other apps.

## 6. Other software (what is verified vs adaptation)

HyperFrames is the only verified toolchain. Everything below is adaptation, UNVERIFIED in your projects.
- **Premiere Pro / After Effects**: set Poppins weight via the style name (e.g. "Poppins SemiBold"), because static files are separate families on Windows. Box = shape layer/Essential Graphics rect, colour #4f8462, rounded 16. Text shadow: opacity 30%, distance 1, blur 2, angle 90 (approximation of `0 1px 2px`). CSS px ≈ pt at 1080 px width compositions; leading = size x 1.25. Premiere cannot do per-word blur; use a Text animator in AE (opacity, position Y 12, Gaussian blur 4).
- **DaVinci Resolve**: Text+ with a rectangle background; per-word reveal needs Fusion modifiers; font list reads installed fonts.
- **CapCut**: Poppins is installed font only if added to CapCut fonts; no boxed per-word animation, closest is "Bubble" text plus word-in animation.
- **FFmpeg/libass/drawtext**: no blur-in or scale boxes; use `drawbox` + `drawtext` with `fontfile=`. Montserrat VF renders at default Thin; use static weights. Bengali needs a libass/harfbuzz build with complex-text shaping (`textshaping`); verify conjuncts.
- **Python (Pillow/MoviePy)**: Pillow needs `libraqm` for Bengali shaping. Measure widths like `textfit.py` (uharfbuzz), shaping Bengali runs with `script="beng"`.
- Differences to expect: browser vs native text engines differ in line-height rounding (~1-2 px), Bengali conjunct shaping, and variable-font weight handling.

## 7. Instructions for Claude: Recreating Our Exact Caption Typography Workflow

1. Read this whole file, then `Presets/caption_presets.json`, then `Reference_Code/reel05_build.py` and `lib.py`.
2. Locate the library (this folder) and run `python Scripts/verify_fonts.py`.
3. Check which fonts the target tool needs. For HyperFrames, copy the needed `.ttf` into the project `assets/fonts/` and use the `FONTS_CSS` from `lib.py`. For other apps, check system installs.
4. If a font is missing, ask permission, then use `Scripts/install_fonts.*`. Opekkha: do not copy it to anyone else; fetch from FontBD.
5. Verify family, weight and version against the manifest (PostScript name and sha256).
6. Pick the preset: 9:16 Bangla explainer -> `SAGE-REEL-916`; 16:9 film -> `SAGE-FILM-169`; personal-story reel with orange accent -> `ORANGE-BN-REEL-916`. If unclear, ask.
7. Apply the preset values exactly. Don't add strokes, uppercase, or new colours.
8. Time each caption to the transcript (word-level), hold until the next caption, never cross cuts, wait 0.35 s after reframes.
9. Keep captions inside x 50-1030, off the face (stack mode `bottom:1010`, full `bottom:330`), off panels.
10. Same preset for the whole video; only the `*emphasis*` words change.
11. After render, extract frames (`ffmpeg -ss T -i out.mp4 -frames:v 1 f.png`) at several captions and check: no tofu boxes, Bengali conjuncts correct, no fallback font look, no box overflow past 1030 px, no overlap with face/panels, caption present on every spoken second.
12. Follow the documented rules. **Never silently substitute a font.** If a font cannot be installed, stop, say which, and name the closest alternative: Opekkha -> Hind Siliguri Bold (or Abu Sayed); Poppins -> Montserrat; Abu Sayed -> Hind Siliguri Light. Wait for approval.

## 9. Troubleshooting

| Symptom | Cause / fix |
|---|---|
| Bengali shows empty boxes | Poppins is first and has no Bengali; Opekkha/Hind not loaded. Check `@font-face` paths and filenames (case-sensitive on Linux/macOS). |
| Latin looks like Arial | Poppins failed to load; check weight file exists (e.g. `Poppins-SemiBold.ttf`). |
| Wrong weight | Windows lists each static weight as its own family ("Poppins SemiBold"); pick that name. Montserrat VF in non-browser tools shows Thin. |
| Conjuncts broken | Renderer lacks complex-text shaping (Pillow without raqm, old FFmpeg). Use the browser renderer. |
| Box overflows frame | `textfit.py` warning "box NNN px wide"; shorten emphasis or follow fit order in 4.2. |
| Two versions installed | Remove the older file, restart app (see install docs). |
| Verification says MISSING for Hind/Instrument | Not installed system-wide; fine for HyperFrames. |
